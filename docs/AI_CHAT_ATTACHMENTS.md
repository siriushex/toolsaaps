# Chat Waiting And Attachments

## Native Motion

The active Focus chat inserts one waiting item only for chatInProgress. Owl and
typing marks share a deterministic draw-only clock. Three restrained cycles end
at7.2seconds; waiting then stays static and indeterminate. There is no fabricated
percentage, model stage, answer or timeout. Completion/failure of the existing
chat cycle removes it; that cycle also includes optional voice-reply preparation.
The header does not duplicate the waiting owl. Root reduced-motion, urgency,
power and lifecycle policy remains; inactive tabs contain no waiting renderer.
Accessibility announces one status, not frame changes; the composer stays fixed.

Direction uses the installed motion skill's pinned art-direction/principles:
240ms base, FastOutSlowIn, no overshoot or sound. This is native UI animation,
not a generated film or ElevenLabs soundtrack.

## Selection And Content

OpenDocument selection is local and never uploads. No persistent URI grant is
retained. Private cache permits4 items,4MiB/item,8MiB total. A fifth is refused,
not substituted. Failed copy deletes only its new partial file. Imports block
send/another picker; registration/removal/send snapshot share one gate. Removed,
completed-send and cleared-VM files are deleted. Process death can leave private
OS-cache files; there is no claimed durable draft or cross-instance purge. Byte
bounds do not guarantee that a document provider cannot block an IO operation.

Send reinspects complete content. Missing, symlinked, empty, oversized, unsupported
or malformed text is refused, never truncated or replaced by filename metadata.
UTF-8 is strict and binary controls are rejected. Names are bounded and have
control/bidi override characters removed. User errors are fixed/localized.

## Actual Routes

- Personal Responses API: JPEG/PNG/GIF/WebP bytes as input_image; PDF bytes as
  inline input_file with filename. Complete text is limited to32KiB total.
  Other binary formats are refused, not represented as analyzed.
- Configured server TEXT: text files up to2KiB total, with labelled untrusted
  data inside the original4096-codepoint/8192-byte signed question envelope.
  Context synchronization, deadlines, capability/archive/no-replay guards remain.
- Server images/PDF/audio remain unavailable. A configured/loading/disabled/broken
  server never falls back to a personal key or repurposes food-only vision.

PDF wire form follows the official [file-input contract](https://developers.openai.com/api/docs/guides/file-inputs).
Synthetic request bytes are not live provider acceptance or clinical validation.
Selection is not upload; send is explicit. No target/dose/therapy/alert authority.
